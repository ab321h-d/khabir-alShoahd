# خبير الشواهد — نموذج تفاعلي مستقل

نموذج React/Vite عربي من اليمين إلى اليسار لرحلة جمع شواهد الأداء: الالتقاط، التصنيف، التأمل، تجميع الحزمة، والمشاركة المقيدة.

## التشغيل

```bash
pnpm install
pnpm dev
```

## البناء والنشر

```bash
pnpm build
```

انشر محتويات `dist/public` على أي استضافة ثابتة. لا يعتمد التطبيق على منصة استضافة أو قاعدة بيانات محددة. في الوضع الافتراضي تحفظ المسودة محليًا في المتصفح ويمكن تصديرها بصيغة JSON.

## البيانات والربط الخلفي

مخطط قاعدة البيانات المستقل موجود في `docs/portable-schema.sql`، وخطة النقل في `docs/PORTABLE_ARCHITECTURE_AR.md`. عند إضافة API، عيّن `VITE_API_BASE_URL` ثم استبدل محول التخزين في `client/src/lib/evidenceStore.ts` دون إعادة تصميم الواجهة.
