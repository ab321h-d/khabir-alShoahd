# تحقق بصري: تخصيص الغلاف

تمت مراجعة معاينة الغلاف على شاشة جوال بعرض 346 بكسل بعد تطبيق العنوان المخصص والخط الكلاسيكي والحجم الكبير ومحاذاة بيانات المعلم إلى اليمين مع إخفاء اسم مدير/ة المدرسة. ظهر العنوان كاملًا على سطرين مقروءين، وبقيت بيانات المعلم والعام الدراسي داخل حدود الغلاف دون تداخل، ولم يظهر اسم المدير في الرأس.
