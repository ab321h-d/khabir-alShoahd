# تحقق معاينة التقرير التجميعي

تمت مراجعة معاينة التقرير التجميعي على سطح المكتب ببيانات اختبار محلية بعد استيراد ملفين وتقييم أحدهما. تُظهر المعاينة إطار **A4 أفقيًا** واضحًا، وعنوان التقرير والفترة، والمؤشرات الأربع، وجدول الملفات الفعلية، وأزرار الطباعة والتنزيل والمشاركة.

كما اجتاز الاختبار الآلي نطاق «كل الملفات» ونطاق «تمت مراجعتها»، وطباعة التقرير، ومشاركة PDF الصريحة، والتنزيل الاحتياطي، والتحقق من عدم إصدار طلبات بيانات تلقائية قبل إجراء المستخدم.
