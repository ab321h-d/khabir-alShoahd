# خبير الشواهد: سياسة العمل دون اتصال والخصوصية

## المبدأ التشغيلي

يعمل **خبير الشواهد محليًا أولًا**. يلتقط المعلم الشاهد، ينظمه، يكتب التأمل، ويرتب الحزمة دون حاجة إلى حساب أو شبكة. تحفظ المسودات والبيانات الوصفية في مساحة المتصفح على الجهاز نفسه، ولا يرسل التطبيق محتوى الشواهد تلقائيًا إلى أي خدمة خارجية.

> الاتصال ليس شرطًا للعمل. لا يستخدم التطبيق الشبكة إلا بعد إجراء صريح يطلبه المعلم، مثل تثبيت التحديث، تصدير نسخة احتياطية إلى خدمة يختارها، أو إنشاء مشاركة مقيدة عند ربط API مستقل مستقبلًا.

## ما يبقى محليًا وما يحتاج قرارًا صريحًا

| العملية | الوضع الافتراضي | هل تحتاج إنترنت؟ | ملاحظة الخصوصية |
| --- | --- | --- | --- |
| التقاط الشاهد وتنظيمه | الصورة وبياناتها محلية في IndexedDB | لا | لا يوجد رفع تلقائي ولا رابط خارجي للصورة. |
| التأمل وتجميع الحزمة | محلي على الجهاز | لا | يظل التأمل خاصًا حتى يختار المعلم إظهاره. |
| النسخ الاحتياطي JSON | ملف ينزله المعلم | لا | يختار المعلم مكان حفظ الملف. |
| استعادة نسخة احتياطية | محلي من ملف يختاره المعلم | لا | لا يخرج الملف من الجهاز أثناء الاستيراد. |
| مشاركة الحزمة | غير مفعلة كخدمة في النسخة المحلية | نعم، عند ربط API مستقل | تنشأ فقط بعد قرار مباشر من المعلم. |
| المزامنة متعددة الأجهزة | معطلة افتراضيًا | نعم، عند التفعيل | يجب أن تكون اختيارية وقابلة للإيقاف. |

## التخزين المحلي والحدود العملية

تستخدم النسخة الحالية IndexedDB كالمخزن الرئيسي للمسودات والبيانات الوصفية وملفات الصور نفسها بصيغة Blob، مع localStorage كخيار احتياطي صغير للمسودة إذا تعذر فتح قاعدة المتصفح. تُحفظ كل صورة تحت مفتاح محلي، وتُستعاد كمعاينة داخل الواجهة وتُحذف من الجهاز فقط عند اختيار المعلم ذلك. لا يعتبر التخزين المحلي بديلًا عن النسخ الاحتياطي؛ فقد يمسح المستخدم بيانات المتصفح أو يفقد الجهاز. لذلك يوضح التطبيق خيار **نسخة آمنة** مشفرة بكلمة مرور محلية باستخدام Web Crypto، ويظل الملف الذي ينزله المعلم تحت مسؤوليته وعلى جهازه. لا يمكن استعادة نسخة مشفرة من دون كلمة المرور. النسخة الاحتياطية الحالية تحفظ البيانات الوصفية فقط ولا ترفق ملفات الصور؛ يبقى كل ملف صورة على الجهاز محليًا حتى نضيف تصدير حزمة مشفرة للملفات في إصدار لاحق.

لا ينبغي أن تسجل الواجهة محتوى الشواهد أو التأملات في أدوات تحليلية أو سجلات أخطاء خارجية. وعند بناء المزامنة لاحقًا، تستخدم واجهة API مستقلة، ونقلًا مشفرًا عبر HTTPS، ورموز وصول قصيرة الصلاحية، مع إتاحة تعطيل المزامنة لكل معلم.

## التثبيت والتشغيل خارج الشبكة

يوفر التطبيق manifest وservice worker لكي يمكن تثبيته كتطبيق ويب تقدمي على أجهزة الجوال والحاسب. بعد فتحه مرة واحدة أثناء وجود اتصال، يحتفظ المتصفح بواجهة التطبيق الأساسية ويعيد تشغيلها دون شبكة. يحتاج التثبيت والتحديثات إلى HTTPS في بيئة الإنتاج؛ أما `localhost` فيكفي للتطوير.

## حدود الادعاء الأمني

حماية التطبيق من الإنترنت لا تحمي جهازًا مشتركًا أو غير مقفل. لذلك يوصى بتفعيل قفل الجهاز وملف مستخدم منفصل في الحاسب، وعدم حفظ ملفات النسخ الاحتياطية في مساحة سحابية مشتركة دون تشفير. لا يدعي التطبيق «خصوصية مطلقة»؛ بل يطبق مبدأ تقليل نقل البيانات ويمنح المعلم قرارًا مباشرًا قبل أي اتصال خارجي.
