# تطبيق المدير المستقل — دليل البناء والنشر

## البنية المعتمدة

أصبح المشروع ينتج تطبيقين مستقلين من **قاعدة كود واحدة**. لا يحتاج ذلك إلى نسخ مشروع المدير أو صيانته في مستودع مختلف.

| التطبيق | أمر البناء | مجلد النشر | النطاق المقترح |
|---|---|---|---|
| خبير الشواهد للمعلم | `pnpm run build:teacher` | `dist/teacher` | `app.اسم-نطاقك` |
| خبير الشواهد للمدير | `pnpm run build:director` | `dist/director` | `manager.اسم-نطاقك` |
| الحزمتان معًا | `pnpm run build:apps` | المجلدان أعلاه | للتحقق المحلي فقط |

## ما الذي ينفصل؟

تحتوي حزمة المدير على شاشة المدير وملف Manifest وService Worker ورمز تثبيت خاص بها. لا تدخل رحلة المعلم في ملفات JavaScript الخاصة بحزمة المدير. وبالمثل، لا تدخل واجهة المدير في حزمة المعلم. يبقى الكود المشترك، مثل التصدير والتخزين المحلي، في ملفات مشتركة داخل المستودع.

| الجانب | المعلم | المدير |
|---|---|---|
| اسم PWA | خبير الشواهد | خبير الشواهد للمدير |
| رمز التثبيت | رمز خبير الشواهد | رمز لوحة مراجعة بعلامة تحقق |
| التخزين | شواهد وصور ومسودات المعلم | ملفات PDF وتقييمات المدير فقط |
| البداية | إضافة الشواهد وتجميع الحزمة | الوارد والمراجعة والتقرير |
| التشغيل | متاح دائمًا على جهاز المعلم | متاح دائمًا على جهاز المدير |

## إعداد Cloudflare Pages

أنشئ **مشروعي Pages** مرتبطين بالمستودع نفسه. لا يحتاج أي منهما إلى أسرار أو متغيرات بيئة في الإصدار المحلي أولًا.

| مشروع Pages | Build command | Build output directory | النطاق |
|---|---|---|---|
| `khabir-teacher` | `pnpm run build:teacher` | `dist/teacher` | `app.اسم-نطاقك` |
| `khabir-director` | `pnpm run build:director` | `dist/director` | `manager.اسم-نطاقك` |

تدعم Cloudflare Pages ربط أكثر من مشروع بالمستودع نفسه؛ يحدد كل مشروع أمر البناء ومجلد الإخراج الخاصين به. راجع دليل Cloudflare Pages في [حزمة النقل المستقلة](./INDEPENDENT_PILOT_DEPLOYMENT_AR.md).

> لأن `app` و`manager` نطاقان مختلفان، لا يمكنهما قراءة IndexedDB لبعضهما. هذه نتيجة مقصودة: تبقى شواهد المعلم على جهازه، بينما يبقى ملف PDF والتقييم في مساحة المدير فقط. يتم الربط بينهما بإرسال PDF يدويًا واستيراده، لا بمزامنة خفية.

## التحقق قبل النشر

شغّل الأوامر التالية من جذر المشروع:

```bash
pnpm check
pnpm test
pnpm run build:apps
pnpm run verify:apps
```

يتحقق الأمر الأخير من أن اسم Manifest ورمز كل تطبيق صحيحان، وأن حزمة المدير لا تضم واجهة المعلم والعكس. بعد النشر، ثبّت كل نطاق من جهاز مستقل وتحقق من الاستيراد والتصدير والنسخة الاحتياطية والعمل دون إنترنت.
