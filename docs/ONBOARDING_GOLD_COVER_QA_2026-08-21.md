# مراجعة الإرشاد الأولي والغلاف الذهبي

تُظهر معاينة PDF للقالب الذهبي إطارًا ذهبيًا رسميًا كامل الصفحة مع زوايا زخرفية محدودة وتباين جيد لبيانات المدرسة والعنوان. اجتاز فحص المتصفح ظهور الإرشاد الافتتاحي، وتوفر زر «ليس الآن» وتسجيل التجاوز محليًا. تؤكد لقطة الواجهة الكاملة بعد زوال شاشة التحميل ظهور نبض ذهبي على زر الإعدادات وبطاقة قصيرة بسهم يشير إليه، مع زري فتح الإعدادات والتجاوز.
