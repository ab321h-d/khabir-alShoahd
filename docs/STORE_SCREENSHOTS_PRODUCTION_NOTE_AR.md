# ملاحظة إنتاج لقطات المتجر

أُنتجت لقطات متجر عمودية حقيقية بدقة **1080×1919 بكسل** من واجهتي المعلم والمدير. تُظهر لقطتا المعلم الشعار الرسمي وترويسة الهوية الفاتحة والحزمة وشريط التقدم، ثم التصدير والمشاركة والطباعة. وتُظهر لقطتا المدير الشعار نفسه ومساحة المدير وزر استيراد PDF المحلي، ثم لوحة المتابعة التجميعية. النصوص الرئيسية والشعار واضحان عند القياس العمودي، ولم تُستخدم بيانات مستخدمين أو تقييمات مصطنعة.

توجد ملفات النشر الفردية في المسار `/home/ubuntu/khabir-alshawahid-store-screenshots/`، مع ملف README يربط كل لقطة برسالتها المقترحة داخل صفحة المتجر.
