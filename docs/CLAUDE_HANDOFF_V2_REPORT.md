# تقرير تنظيف وتسليم Claude — خبير الشواهد

**الإصدار المستهدف:** `Khabeer-Shawahid-Claude-Handoff-v2`  
**الغرض:** تسليم نسخة مستقلة محليًا أولًا، بلا تجربة زمنية أو ترخيص أو تفعيل أو قفل قراءة فقط.

## النتيجة التنفيذية

أزيل نظام التجربة المؤقت بالكامل من التشغيل. لم يعد التطبيق يحسب أيامًا متبقية، أو يقرأ وقت الجهاز لتحديد الصلاحية، أو يوقف الإضافة والتعديل والاستيراد. تعمل مساحة المعلم والمدير دون حسابات أو خادم أو مفاتيح تفعيل، مع بقاء التخزين المحلي وPWA والتصدير والطباعة والنسخ الاحتياطي والاستعادة كما كانت.

أعيد الشعار الخفيف إلى رأس الجوال بجانب اسم «خبير الشواهد». أبقي التعديل خفيفًا: لم يُضف تصميم جديد أو حركة أو طبقة مرئية ثقيلة.

## Reference Chain قبل الإزالة

| الطبقة | المرجع السابق | دوره السابق |
|---|---|---|
| الحالة | `client/src/lib/localTrial.ts` | إنشاء حالة مدة الاستخدام، حفظها محليًا، مقارنة الوقت، وإنتاج حالة الانتهاء. |
| المعلم | `client/src/pages/Home.tsx` | قراءة الحالة، تعطيل الإضافة والتعديل والصور والغلاف وترتيب البنود، وإظهار بطاقة الحالة في الإعدادات. |
| المدير | `client/src/pages/Director.tsx` | تعطيل استيراد PDF وتعديل التقييم والحذف وإظهار حالة القراءة فقط. |
| الاختبارات | `client/src/lib/localTrial.test.ts` و`export-smoke.mjs` و`director-smoke.mjs` | اختبار بداية المدة وانتهائها ومنع الوظائف بعدها. |
| التوثيق | `LOCAL_TRIAL_LICENSE_AR.md` و`DISTRIBUTION_LICENSE_STRATEGY_AR.md` | وصف نظام التجربة والترخيص المؤقت. |
| التنسيق | `client/src/index.css` | بطاقة الحالة وشريط التقدم ورسائل الانتهاء. |

## Reference Chain بعد الإزالة

| الطبقة | الوضع الحالي |
|---|---|
| المعلم | عمليات إضافة الشواهد وتعديلها وحذفها وترتيب البنود والصور والغلاف متاحة دائمًا. |
| المدير | استيراد PDF وتعديل المراجعة والحذف والتقارير والطباعة والتصدير متاحة دائمًا. |
| التخزين | IndexedDB وlocalStorage يستمران للمسودات والصور والتفضيلات والنسخ الاحتياطي فقط؛ لا توجد حالة صلاحية تنفيذية. |
| الاختبارات | تختبر تدفقات الإضافة والتعديل والتصدير والاستعادة واستيراد المدير بصورة دائمة، من دون حقن حالة انتهاء. |
| PWA | يبقى Service Worker وManifest والعمل دون اتصال في ناتج الإنتاج. |

## البحث النهائي عن المصطلحات المؤقتة

لا توجد مراجع تنفيذية إلى حالة التجربة أو الترخيص أو التفعيل أو انتهاء الصلاحية أو مدة 90 يومًا في `client` أو `server` أو `shared` أو `scripts` أو وثائق المنتج. الاستثناء الوحيد هو **هذه الوثيقة التدقيقية** لأنها تسجل ما أزيل لأغراض التسليم فقط.

تبقى ثلاثة أنواع من المطابقات غير المرتبطة بالترخيص عند البحث الموسع:

| المطابقة | الموضع | التصنيف |
|---|---|---|
| `expiry` | `evidenceStore.ts` و`Home.tsx` | مدة رابط المشاركة المقيدة، وهي وظيفة أصلية مستقلة وليست صلاحية استخدام التطبيق. |
| `readonly` | مخازن IndexedDB واختبار التصدير | وضع قراءة تقني لمعاملات قاعدة البيانات المحلية فقط، وليس واجهة مستخدم أو قفل تطبيق. |
| `license` | `package.json` | قيمة رخصة المصدر `MIT`، وليست مفتاح تفعيل أو منطق بيع. |

## تأكيد الوظائف الأصلية

أثبتت تدفقات الاختبار أن إنشاء الشواهد وتعديلها وحذفها واستيراد البيانات وPDF وWord وExcel والطباعة والمشاركة والنسخ الاحتياطي والاستعادة والإعدادات ومساحة المدير وإعادة التحميل والعمل دون اتصال ما زالت تعمل. لا تُرفع البيانات تلقائيًا، ولا يحتاج التطبيق إلى حساب أو خادم أو وقت جهاز لتحديد قابلية الاستخدام.

## ملاحظات متبقية

قد تبقى في بعض متصفحات المستخدمين قيمة قديمة غير مستخدمة داخل localStorage من نسخة سابقة. لا يقرأها التطبيق الحالي ولا ينشئها ولا تؤثر في أي وظيفة. يمكن حذفها فقط من إعدادات المتصفح إن رغب المستخدم، لكنها ليست جزءًا من النسخة المسلّمة أو من منطقها التشغيلي.
